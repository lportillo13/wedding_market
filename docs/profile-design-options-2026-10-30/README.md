# Profile design options

The owner reported mixed widths and a profile style inconsistent with the rest of
Wedding Market, then requested alternatives. These new profile options all use the
selected **header A**, the supplied GT Super/Acumin typography, warm ivory/champagne
and brown, thin dividers and consistent outer alignment. No profile style has been
selected or published.

- **Profile A — Editorial sections (recommended):** a small integrated photo row,
  light numbered sections, headings at left and fields at right, without separate
  heavy cards.
- **Profile B — Side summary:** a deliberate two-column grid with photo/identity
  at left and consistently aligned contact/wedding panels at right.
- **Profile C — One paper panel:** photo, contact details and wedding preferences
  share one continuous surface with a single save footer.

[A](option-a.jpg), [B](option-b.jpg), [C](option-c.jpg) are code-rendered design
previews with fictional contact data. All existing fields are represented. Future
implementation must preserve optional guest/budget estimates, the distinction
between contact country and Costa Rica wedding location, locked credential email,
language persistence, authenticated photo uploads and profile saves. Prototype
source is in ignored `.cache/profile-design-options/server.cjs`. The temporary
preview server and viewport override are cleaned up after delivery.
