# Browser color matches Wedding Market

The owner requested the browser bar color to match the website. The existing older brown is replaced by the current palette: opaque warm ivory `#faf8f4` for content, detail and fitting pages and the mobile menu; warm brown `#332d27` for actual homepage, vendor and boutique covers. Cover pages keep brown after scrolling, matching the persistent header. The installed web-app manifest uses the same brown theme and ivory launch background.

The root Next viewport provides one ivory fallback meta tag. `BrowserThemeColor` updates that existing tag after client rendering, route changes, mobile menu changes and boutique gallery/form transitions that keep the same pathname. The cover observer watches child additions/removals only, is limited to cover routes, batches into one animation frame and disconnects on cleanup. It does not observe text/attributes, add a scroll listener, fetch data or cache private results. Empty covers, missing content, details and fitting forms retain paper styling. Existing navigation, Apple standalone status-bar behavior, service-worker policy and native source/publication remain unchanged.

Architecture, TypeScript, lint, production build and 109 web tests pass. Local browser checks confirm one meta tag, ivory content/favorites/missing-page states, brown home/vendor/boutique covers, brown after scrolling, ivory open menu/search states and restored brown on close. Outfit and appointment views update within the same boutique pathname, including returning to the cover. SPA/back navigation also restores the correct value. The initial vendor measurement occurred before its asynchronously loaded cover existed; it retained ivory until the cover rendered, then correctly changed to brown. See `local-browser-checks.json` for the raw measurements and loaded-state follow-up.

This is the standard suggested browser theme color, not a guarantee of a particular address-bar appearance on every browser. Testing covers metadata/state transitions rather than physical mobile-browser chrome painting. References: [HTML standard](https://html.spec.whatwg.org/multipage/semantics.html#meta-theme-color), [browser support and metadata behavior](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/meta/name/theme-color). Release evidence will follow.
